# AAA
<img src="build/AAA_icon.png" width="100px">

Asset Administration Assistant

## 기술 스택

**데스크톱 프레임워크**: Electron  
**프론트엔드**: React, Vite, JavaScript, CSS  
**백엔드**: Node.js (Electron 환경)  
**데이터베이스**: SQLite (`node:sqlite`)  
**아이콘**: [Lucide React](https://github.com/lucide-icons/lucide)
